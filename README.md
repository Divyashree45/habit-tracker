# Habit Tracker

A simple Habit Tracker web application built using HTML, CSS, and JavaScript.

## Features

- Add new habits
- Select Daily or Weekly frequency
- Mark habits as completed
- Track daily streaks
- View progress
- Edit habits
- Delete habits
- Search habits
- Filter habits by frequency
- Save habits using Local Storage
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Git
- GitHub
